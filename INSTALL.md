# Deployment guide

1. `DeVolaris.md` is the complete proposed **README.md** for `DeVolaris/DeVolaris` (not `DeVolaris.md` at repository root if you want it displayed as a profile!). Preserve existing `DeVolarisGroup-logo-w.png` in that repo.
2. `DeVolarisCloud.md` is the proposed **README.md** for `DeVolarisCloud/DeVolarisCloud`.
3. Upload `assets/devolaris-cloud-banner.png` to `DeVolarisCloud/DeVolarisCloud/assets/devolaris-cloud-banner.png` before or with the Cloud README. The relative path must match.
4. Upload `assets/devolaris-cloud-avatar.png` as the GitHub avatar using Settings → Public profile → Edit picture; it cannot be set by modifying README.
5. Enter profile fields from `PROFILE_FIELDS.md` in each account's GitHub Settings → Public profile.
6. On each profile repository, verify name exactly matches login; the README in the default branch is displayed automatically.
7. Review broken links and external assets before publishing. Repositories named in the group README were confirmed visible on 2026-10-22.
8. The supplied image is a new illustrative brand concept, not a reconstruction of the original logo. Approve its brand fit before substituting for production artwork.
9. No account changes or GitHub commits were made.
